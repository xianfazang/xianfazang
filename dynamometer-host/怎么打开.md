# 怎么打开测功机上位机

两种办法，任选一种即可。

## 办法 A：下载现成程序（推荐，不用装 Python）

1. **下载**：[dynamometer-host-Mock.zip](https://github.com/xianfazang/xianfazang/releases/download/phase0-mock-ui-v0.1.1/dynamometer-host-Mock.zip)  
   （发布页：https://github.com/xianfazang/xianfazang/releases/tag/phase0-mock-ui-v0.1.1 ）
2. **解压**到任意文件夹（例如桌面）。
3. **双击** `测功机上位机.exe`。

若杀毒软件提示未知来源，选「仍要运行」即可（未做官方签名时常见）。

## 办法 B：已安装 Python 时，用源码一键启动

1. **下载**：[源码 zip](https://github.com/xianfazang/xianfazang/archive/refs/heads/cursor/phase0-windows-exe-9708.zip)
2. **解压**，进入里面的 `dynamometer-host` 文件夹。
3. **双击** `打开测功机.bat`（或 `open.bat`）。第一次会自动装依赖，稍等即可。
